# Certificates Directory

Place your PDF certificate files in this folder with the following filenames:
- `certificate1.pdf` (e.g. Google Cloud Generative AI Internship Certificate)
- `certificate2.pdf` (e.g. Academic/Course Certificate)

The "View Certificate" buttons in `index.html` link directly to:
- `assets/certificates/certificate1.pdf`
- `assets/certificates/certificate2.pdf`
